# 보 다이어그램 계산기

보의 지점·하중을 입력하면 반력, 전단력도(SFD), 휨모멘트도(BMD)와 손계산 형식의 풀이 과정을 보여주는 도구.

> 현재 진행: **Phase 5B (부정정보) 완료** — 다음: 5C PDF 출력
>
> 배포 주소: https://ruberose.github.io/beam-diagram/

## 웹 화면 실행

Pyodide는 파일을 더블클릭해서 여는 방식(`file://`)에서는 동작하지 않는다. 로컬 웹 서버로 연다.
프로젝트 루트(이 README가 있는 폴더)에서:

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/web/` 을 연다.
처음 열 때 Pyodide·SymPy를 받느라 수 초~수십 초 걸리고, 이후에는 브라우저 캐시를 쓴다.
같은 와이파이의 아이패드에서 보려면 `http://<PC의 IP>:8000/web/` (방화벽 허용 필요).

- 입력은 브라우저(localStorage)에 자동 저장되어 다시 열면 복원된다.
- 오른쪽 위에 Pyodide 안의 SymPy 버전과 측정된 부호 보정값이 표시된다.
- 외부 라이브러리(CDN, 버전 고정): Pyodide 0.27.2, Plotly.js 2.35.2, KaTeX 0.16.11

## GitHub Pages 배포

서버 없이 정적 파일만으로 동작하므로 GitHub Pages에 저장소 루트를 그대로 올린다.
주소: `https://<계정>.github.io/<저장소>/` → 루트 `index.html`이 `web/`으로 이동시킨다.

### 처음 설정 (한 번만)

1. GitHub에 저장소를 만들고 이 폴더를 올린다 (무료 계정은 **공개(public)** 저장소여야 Pages 사용 가능).
   ```bash
   gh repo create <저장소> --public --source . --push
   ```
2. 저장소 → Settings → Pages → Build and deployment
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더: **/ (root)** → Save
   - 명령줄로 하려면:
     ```bash
     gh api -X POST repos/<계정>/<저장소>/pages -f "source[branch]=main" -f "source[path]=/"
     ```
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 접속.

### 이후 업데이트

`main` 브랜치에 push하면 자동으로 다시 배포된다 (1~2분).

```bash
git push
```

### 주의

- 루트의 `.nojekyll` 파일을 지우지 말 것. GitHub Pages는 기본으로 Jekyll을 거치는데,
  Jekyll은 `_`로 시작하는 파일을 빼버려서 `core/__init__.py`가 배포되지 않는다.
- 배포본에서도 브라우저 캐시 때문에 옛 화면이 보이면 강력 새로고침(Ctrl+F5, 아이패드는 탭 닫고 다시 열기).

## 단위

길이 m, 힘 kN, 분포하중 kN/m, 모멘트 kN·m 고정. 표시는 소수 2자리.

## 부호 규약 (실무 규약)

| 항목 | 양(+)의 방향 |
|---|---|
| 하중 입력 P, w | 아래 방향 |
| 모멘트 하중 입력 | 시계방향 |
| 반력 R | 위 방향 |
| 반력 모멘트 (고정단) | 시계방향 (모멘트 하중과 같은 규칙). 표시할 때 회전 방향 ↻/↺ 도 함께 보여줌 |
| 전단력 V | 단면 왼쪽 부분이 위로 밀리는 방향 (단순보 등분포 왼쪽 끝 V = +wL/2) |
| 휨모멘트 M | 하부 인장 (단순보 등분포 중앙 M = +wL²/8) |
| 처짐 δ | 아래 방향 (단순보 등분포 중앙 δ = +5wL⁴/384EI) |
| 처짐각 θ | 시계방향 = dδ/dx (단순보 등분포 왼쪽 지점 θ = +wL³/24EI) |

### SymPy 규약 확인 결과

SymPy 규약은 가정하지 않고 `core/sign.py`가 **실행할 때마다 답을 아는 보 2개를 풀어서 측정**한다
(SymPy 버전이 바뀌어도 자동으로 맞춰짐). PC의 SymPy **1.14.0**과 Pyodide 0.27.2 안의 SymPy **1.13.3**에서 측정한 결과가 같았다:

| 항목 | SymPy 규약 | 변환 |
|---|---|---|
| 하중 값 | 실무 "아래 +" 하중을 `+`로 넣으면 V·M이 실무와 같은 부호로 나옴 | 그대로 |
| 반력 | 하중과 같은 규약(아래 +)으로 나옴 → 예: 단순보 등분포 R = −wL/2 | 부호 반전 |
| 전단력 V | 실무와 동일 | ×(+1) |
| 휨모멘트 M | 실무와 동일 (하부 인장 +) | ×(+1) |
| 모멘트 하중 / 반력 모멘트 | `+` = 반시계방향 | ×(−1) |
| 처짐 δ, 처짐각 θ | 실무와 동일 (아래 +, 시계 +) | ×(+1) |

## 지원 범위

- 정정보: 단순보(핀+롤러, 임의 위치 → 내민보 포함), 캔틸레버(고정단 1개, 왼쪽 또는 오른쪽 끝)
- 부정정보 (Phase 5B): 고정-핀(롤러), 양단 고정, 2~3경간 연속보 (핀·롤러 3~4개)
- 롤러만 있는 구성은 수평 방향으로 불안정하므로 거부한다 (핀이나 고정단이 하나는 있어야 함)
- 하중: 집중하중, 등분포(전체/부분), 선형 분포(삼각형·사다리꼴, 시작·끝 값 입력), 집중 모멘트
- EI는 보 전체에서 일정. 지점 침하·온도하중·축력은 범위 밖

## 처짐 (Phase 5A)

입력 패널의 "단면 강성"에 E [MPa]와 I [mm⁴]를 모두 넣으면 처짐을 계산한다 (비우면 계산 안 함).

- 휨강성 환산 (고정식): EI [kN·m²] = E × I × 10⁻⁹ (1 MPa = 10³ kN/m², 1 mm⁴ = 10⁻¹² m⁴)
- 그래프 맨 아래에 처짐도(mm, 아래 처짐이 축 아래로) 추가, 최대 처짐·최대 솟음 위치에 라벨 표시
- 풀이 과정 "5. 처짐 (맥컬리법)": EI·δ'' = −M → 두 번 적분 → 경계조건으로 C₁, C₂ → θ = 0 위치 → δ_max.
  손으로 만든 δ(x)를 SymPy 결과와 비교해서 다르면 경고를 낸다.
- 허용처짐: |δ|max ≤ L/n (n 기본 360, 기준 길이 = 보 전체 길이) → OK / NG
- EI는 보 전체에서 일정하다고 가정한다.

## 부정정보 (Phase 5B)

반력은 SymPy가 적합조건(지점 처짐 = 0, 고정단 처짐각 = 0)으로 풀고, 풀이 과정은 **변형일치법**으로
따로 계산해서(`core/compat.py`) SymPy 해와 정확히 같은지 비교한다. 다르면 경고.

| 구조 | 여분력 | 이완 구조(정정보) |
|---|---|---|
| 고정-핀 | 핀·롤러 반력 | 캔틸레버 |
| 양단 고정 | 오른쪽 고정단의 R, M | 왼쪽 고정 캔틸레버 |
| 연속보 | 안쪽 지점 반력 | 양 끝 지점의 단순보 |

1. 적합조건 Δᵢ = Δᵢ₀ + Σ fᵢⱼXⱼ = 0 (Δᵢ₀: 하중에 의한 이완 구조 변위, fᵢⱼ: 단위 여분력에 의한 변위)
2. 변위는 맥컬리법으로 구하고 EI를 곱한 값으로 다룬다 → EI가 지워지므로 E, I 없이도 반력이 나온다
3. 여분력을 하중으로 보고 이완 구조의 평형식으로 나머지 반력
4. 처짐 단계에서 경계조건에 쓰지 않은 나머지 지점의 δ = 0 (θ = 0)을 검산으로 표시

입력 패널의 지점 프리셋 버튼(고정-핀, 양단 고정, 2경간, 3경간)은 현재 경간 L 기준으로 지점을 채운다.

## 풀이 과정 (Phase 2)

`core/steps.py`가 손계산 순서대로 단계별 LaTeX를 만든다. 단계마다 일반식 → 숫자 대입 → 결과.

1. 하중 정리 — 분포하중을 합력 W와 작용점 x̄로 (사다리꼴은 직사각형 + 삼각형으로 분할)
2. 반력 계산 — ΣM_A = 0 → R_B, ΣF_y = 0 → R_A (캔틸레버: ΣF_y → R_A, ΣM_A → M_A). 부정정보는 변형일치법
3. 구간별 V(x), M(x) — 단면 왼쪽 자유물체도로 식을 세움
4. 최대값 — V(x) = 0 위치(1차식 풀이 / 근의 공식) → M 대입, 구간 경계값과 비교
5. 처짐 — 맥컬리법 (E, I를 넣었을 때만)
6. 특이함수 식 — 기본 숨김

반력과 구간식은 SymPy 결과를 옮겨 적지 않고 하중 목록에서 **직접** 계산한 뒤,
SymPy 결과와 정확히 같은지 비교한다. 다르면 경고를 낸다.

  model.py      지점·하중·보 데이터 클래스
  sign.py       SymPy 규약 ↔ 실무 규약 변환 (자동 보정)
  solver.py     SymPy Beam 래핑 → 반력, V(x), M(x)
  piecewise.py  특이함수 식 → 구간별 식, 임의 위치 값
  extremes.py   최대/최소값과 위치 (V=0 위치 포함)

  macaulay.py   맥컬리법 손계산 도구 (정정 반력, M(x) 특이함수 식, 두 번 적분)

web/         브라우저 화면 (Pyodide)
  index.html    화면 뼈대
  app.js        Pyodide 로딩, 입력, 그래프(Plotly)·수식(KaTeX) 렌더링
  style.css     모양 (폭 1000px 미만은 위아래로 쌓임)
  bridge.py     JSON 입력 → core 호출 → JSON 출력 (웹과 엔진 사이의 유일한 통로)
tests/       pytest 테스트 (교과서 공식, 처짐 공식, 부정정 공식, 풀이 과정, bridge JSON)
